# Visual quality release rubric

Score the **actual rendered figure** at every intended viewing size. For each
applicable gate, record one concrete observation and assign **0 = observed
failure**, **1 = unverified or ambiguous**, or **2 = observed pass**. A candidate
may be shown for feedback, but do not replace an accepted figure until every
applicable gate scores 2 and any requested user-preview approval is received.

| Gate | Observed pass |
|---|---|
| Meaning and direction | A reader can trace input → process → output; arrows, comparison links, geographic/data claims, and counts match the checked content map. |
| General-audience language | First-use abbreviations are expanded or plainly explained nearby; stage labels explain function without unexplained specialist shorthand. Avoid visible instructional scaffolding such as “Plain-language guide” or “How to read this”; the figure should teach through its own labels. |
| Layout and legibility | Main elements use a deliberate grid; labels align with their objects; visual weight and whitespace are balanced; there is no crop, seam, collision, or floating explanation. Necessary text meets the brief's display-size threshold. Purposeful breathing room is allowed. |
| Editable handoff, when requested | Exact labels and connectors are native editable objects; illustrations move separately; a label, image, and connector survive edit → save → reopen. |
| Replacement evidence, when applicable | Identify the *actual* accepted reference rather than an intermediate candidate; view it beside the revision at matching size. The candidate fixes named defects without collapsing accepted pathways or degrading accepted regions; requested user approval precedes promotion. |

Do not award a visual 2 from a package validator, keyword test, or prompt alone.
If a gate scores 0 or 1, keep the previous accepted figure and fix the defect
or state the missing evidence. An untested audience's comprehension remains
unmeasured even when the figure passes this production rubric.
